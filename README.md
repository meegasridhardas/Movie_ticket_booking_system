# Movie_ticket_booking_system
A mini-project based on the concepts of C programming language.This helps to reserve the movie tickets in online.

Abstract:
Allow users to view movies,select seats, check seat availability and book tickets.It uses structures, arrays, functions and file handling to store booking details and prevent duplicate seat reservation.This project reduce manual work,saves time and provides an easy way to manage movie ticket bookings.

Objectives:
• Display the list of available movies.
• Allow users to select their preferred movie.
• Provide seat selection facilities and check seat availability before confirming a booking.
• Prevent duplicate seat bookings.
• Calculate the total price and store booking details using file handling. And display booking information when required.

Limitation:
The program supports only 4 movies and 10 seats per movie.It accepts movie and seat numbers rather than movie names.It does not collect customer details or generate a unique ticket number.
